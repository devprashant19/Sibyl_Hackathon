The CLI runs from the repository today (`pnpm sibyl <command>`); it is not yet published to npm. The full
reference, with every option, is [`docs/cli.md`](https://github.com/devprashant19/Sibyl/blob/main/docs/cli.md).

## `sibyl run`
Runs a search session against `sibyl.config.ts` and saves it to `.sibyl/sessions/`.

```bash
sibyl run -c sibyl.config.ts -n 200 --seed 0xBEEF --strategy bayesian
```

- `-n, --iterations` — counted runs (duplicate schedules are skipped and don't count). Default `100`.
- `--strategy` — `ucb1` (default), `mcts`, `bayesian`.
- `-s, --seed` — the master seed. The same seed and config reproduce the session.
- `--clock accelerated` — timers fire instantly.
- `--junit <file>`, `--early-exit`, `--concurrency <n>`, `--timeout <ms>`.

Uploads the session when `SIBYL_API_URL` is set.

## `sibyl ci`
`run` without interactive output. Exits `1` if any run failed, errored, or was intermittent
(`--allow-intermittent` to permit flakes).

```bash
sibyl ci -n 200 --junit reports/sibyl.xml
```

## `sibyl replay <run-id>`
Re-executes one run with its original seed and fault schedule, and reports whether the outcome and every
fault decision reproduced. A unique id prefix is enough. Looks locally first, then at `SIBYL_API_URL`.

```bash
sibyl replay 1c72f7b2 --events
```

## Also

`sibyl init` · `sibyl sessions` · `sibyl doctor` · `sibyl explain <run-id>` · `sibyl investigate "<bug>"` ·
`sibyl retro <postmortem.md>` — the last three need `ANTHROPIC_API_KEY`.
