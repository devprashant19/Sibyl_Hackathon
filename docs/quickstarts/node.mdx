title: "Node.js Quickstart"
description: "Find and replay a failure in a Node.js workflow in a few minutes."
---

## 1. Install

The packages are not on npm yet; work inside the repository.

```bash
git clone https://github.com/devprashant19/Sibyl.git
cd Sibyl && pnpm install
mkdir -p packages/cli/examples/mine && cd packages/cli/examples/mine
node ../../bin/sibyl.js init
```

`init` writes a `sibyl.config.ts` that runs as-is: a local payment server and a checkout that retries a
failed payment without an idempotency key.

## 2. Describe the workflow, the faults, and the promise

```ts
import { defineConfig } from '@sibyl/core';

export default defineConfig({
  drivers: ['http'],                       // intercept fetch and http.request
  workflow: async () => {
    charges = 0;
    await checkout();                      // call into your own code here
  },
  templates: [
    { id: '<uuid>', spec: { domain: 'HTTP', type: 'HTTP_5XX' }, probabilityRange: [0, 1] },
  ],
  promises: [
    {
      id: 'charge-at-most-once',
      description: 'A checkout never charges the customer twice',
      severity: 'CRITICAL',
      evaluate: () => ({ passed: charges <= 1, message: `charged ${charges} times` }),
    },
  ],
});
```

## 3. Search

```bash
node ../../bin/sibyl.js run -n 30
```

Each run, the strategy picks a probability for the 503 fault, the HTTP driver injects it into `fetch`,
and the promise is checked. Failing runs are listed with the command to reproduce them.

## 4. Replay

```bash
node ../../bin/sibyl.js replay <run-id> --events
```

`✔ Reproduced: same outcome and same fault decisions.`

Other drivers (Postgres, MySQL, Kafka, SQS, gRPC, filesystem, child processes) wrap a client object;
see [configuration](https://github.com/devprashant19/Sibyl/blob/main/docs/configuration.md#drivers).
